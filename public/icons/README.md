# PWA Icons

This directory should contain the following icon files for the Progressive Web App:

## Required Icon Sizes:
- `icon-72x72.png` - 72x72 pixels
- `icon-96x96.png` - 96x96 pixels  
- `icon-128x128.png` - 128x128 pixels
- `icon-144x144.png` - 144x144 pixels
- `icon-152x152.png` - 152x152 pixels
- `icon-192x192.png` - 192x192 pixels
- `icon-384x384.png` - 384x384 pixels
- `icon-512x512.png` - 512x512 pixels

## Design Guidelines:
- Use a calculator or tax-related icon design
- Ensure the icon works well on both light and dark backgrounds
- Make it "maskable" - keep important content within the safe zone (center 80% of the icon)
- Use your app's brand colors (blue theme: #2563eb)

## Tools for Icon Generation:
- [PWA Builder](https://www.pwabuilder.com/imageGenerator) - Free online tool
- [Favicon.io](https://favicon.io/favicon-generator/) - Generate from text or image
- [RealFaviconGenerator](https://realfavicongenerator.net/) - Comprehensive favicon generator

## Quick Setup:
1. Create a 512x512 base icon with your calculator design
2. Use an online PWA icon generator to create all required sizes
3. Replace this README with your actual icon files

The manifest.json file is already configured to use these icons once they're added to this directory.
